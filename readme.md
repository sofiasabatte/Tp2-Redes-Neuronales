# TP2 : Clasificador de Lesiones Dermatológicas con CNN
 
Continuación del TP1 (MLP), ahora usando CNNs. El objetivo es superar el 60.95% de accuracy en test.
 
**Resultado final: 70.41% en test con ResNet18.**
 
## Estructura

- `1_CNN_Simple.ipynb` — CNN tipo AlexNet + Transfer Learning con ResNet18
- `2_CNN_Busqueda_HP.ipynb` — Random Search de hiperparámetros 
- `Resumen.md` — resumen de todo lo que se probó y los resultados
